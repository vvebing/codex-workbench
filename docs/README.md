## 文档维护

文档中的命令以 `package.json` 和 `scripts/` 为依据，功能行为以应用源码和测试为依据。修改功能时同步更新对应指南，避免在多个文档中重复维护完整操作步骤。中英文首页保持功能、前提与入口一致。

接口矩阵由 `npm run audit:protocol` 生成；使用 `npm run check:protocol` 检查其与源码是否一致。提交前检查相对链接和 Markdown 格式，具体验证命令见[开发指南](development.md)。
