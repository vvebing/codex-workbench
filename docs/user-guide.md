# 使用指南

Codex 工作台将对话、项目文件、审批和多环境任务放在同一个浏览器工作区。安装与服务管理见[运行与运维](operations.md)，所有文档见[文档导航](README.md)。

## 完成第一个任务

1. 启动工作台，打开 `http://127.0.0.1:5180`。
2. 在「设置 → 工作环境」连接 `ws://127.0.0.1:4501`，确认环境在线。
3. 点击「新建会话」，填写该环境中的项目目录；先创建本地草稿，发送首条消息时创建服务端会话。
4. 输入需求，按 Enter 发送；执行过程中可查看命令、文件修改与计划，并处理审批或问题。
5. 点击文件打开编辑器，或进入右侧「Git」核对工作区差异。需要继续工作时发送下一条消息。

界面默认跟随浏览器语言，中文使用简体中文，其余使用英文。在「设置 → 通用 → 语言」可切换；消息、回复和文件内容保留原文。

## 工作环境与导航

一个环境对应一个 app-server 连接，可同时连接本机与多个 SSH 转发的开发机。远端接入步骤见[远端环境](operations.md#远端环境)。工作目录、账户、技能和执行权限都属于所选环境。

侧栏按「项目」或「最近」查看会话，可筛选环境与会话状态。项目按活动时间排序，收藏项目优先；项目默认显示前 5 条会话，可展开其余已加载摘要。「最近」按实际活动时间分组，点击会话不会改变排序。环境筛选只改变列表范围，不中断执行或切换当前对话。

环境范围内的历史摘要会自动分页加载，正文在打开会话时读取。加载失败可重试，离线时可查看已缓存历史；待同步状态不代表任务已经结束。侧栏「定位当前会话」可切回对应范围、展开项目并滚动到当前会话。

「分区筛选与管理」用于在环境内分类会话，会话菜单可将会话移入分区。分区由服务端保存、多个客户端共享；收藏和导航偏好保存在当前浏览器。

### 搜索与会话操作

按 `⌘/Ctrl+K` 搜索。搜索默认使用侧栏环境范围，可选择其他环境或全部环境。关键词匹配已加载内容，并搜索所选在线环境的历史标题；未加载的正文不在搜索范围。服务端标题搜索区分大小写。完整 Session / Thread ID 可精确定位历史会话。

会话标题旁、侧栏行尾和右键菜单提供重命名、收藏、分叉、复制 ID、复制 Markdown、复制最终总结和导出。导出包括消息与会话信息，执行日志在页面中查看。分叉与回滚需等待当前执行结束；回滚会先要求确认。

归档后会话从普通列表移除，可通过提示撤销，或在「设置 → 已归档的会话」恢复。已打开的归档会话为只读。永久删除会连同后代子代理会话和历史一起删除，确认后不能恢复。未发送草稿可以重命名和删除；有内容的草稿删除前会要求确认。

当前会话链接为 `/?env=<环境ID>&session=<会话ID>`，支持刷新和浏览器前进／后退。接收者需先配置指向同一服务的相同环境 ID；链接不携带地址或凭据。草稿只在保存它的浏览器中恢复。

## 输入与发送

| 操作                         | 快捷键或入口       |
| ---------------------------- | ------------------ |
| 发送；执行中按偏好排队或引导 | Enter              |
| 换行                         | Shift+Enter        |
| 引导当前执行                 | ⌘/Ctrl+Enter       |
| 加入队列                     | ⌘/Ctrl+Shift+Enter |
| 引用项目文件                 | 输入 `@`           |
| 引用技能                     | 输入 `$`           |
| 查看快捷命令                 | 输入 `/`           |

补全列表用方向键选择，Enter 或 Tab 确认，Escape 关闭。中文输入法确认候选时不会发送。文件与技能引用以完整标签编辑；粘贴到外部应用时输出路径或技能名称。

发送时立即清空已提交的输入，之后新写的内容继续保留。创建或投递失败的记录可「恢复到输入框」，保留引用与图片，并与已有草稿合并。显示「发送结果待核实」时先检查会话历史，再决定是否重试；断线不会自动重放消息或审批回答。其他客户端占用会话写入时，输入保留，可稍后重试。

### 模型与权限

输入区可选择服务端提供的模型、推理强度、审批策略和服务档位。在「设置 → 工作环境 → 模型与权限」可设置本浏览器的新会话偏好，以及写入所选设备用户配置的默认模型与默认审批策略。项目显式模型优先于浏览器偏好，已有会话保留自身设置。

「沿用当前审批设置」使用服务端已确认值；显式选择的覆盖在新轮次发送后生效，也影响后续轮次，选回沿用不会撤销已经生效的覆盖。审批设置不控制沙箱。尚未确认的设置显示为「下次」。队列保存入队时的配置，立即引导沿用正在执行轮次的配置。问题卡片使用会话设置，不采用输入区尚未发送的选择。

### 文件与图片附件

可以选择、粘贴或拖入图片，也可添加其他文件。每个附件最多 5 MB；图片支持 PNG、JPEG、WebP、GIF，最多 4 张，编码后总量最多 10 MB。图片输入需要模型声明支持。点击缩略图可预览，Escape 关闭。

上传或粘贴的附件保存在**所连接执行环境**的 `~/.codex-workbench/attachments/<上传ID>/`。在「设置 → 工作环境 → 附件存储」可填写 `~/` 开头或绝对路径；此偏好保存在当前浏览器，作用于后续上传。非图片附件作为绝对路径引用，能否解析取决于环境中的工具。移除引用不会删除已保存文件。

从文件树拖入文件或输入 `@` 会引用项目原文件。参考资料面板中的链接或路径则是会话关联信息，需要插入输入框并发送后才成为消息内容，不会自动读取链接或上传文件。

## 队列与待办

「设置 → 通用 → 会话交互」可选择执行中发送的默认行为：排队或引导当前任务，默认排队。Enter 与主按钮遵循该偏好，快捷键可执行单次引导或排队。

排队消息在当前任务完成后依次启动下一轮。每项保存文字、文件与技能引用、图片、模型及审批配置，可编辑、删除、移到最前或立即引导；编辑队列项不会覆盖输入框草稿。

停止、失败、刷新或重连后队列暂停，核对后点击「继续队列」。关闭页面期间不会继续发送。结果待核实时，已送达的任务应删除，确认未送达后才重试。队列使用 IndexedDB，按环境、服务地址和会话隔离；不可用时仅保存在页面内存。支持 Web Locks 的浏览器会协调多标签页调度。

侧栏「待办中心」汇总已知的待审批、待回答、失败或待核实、暂停队列及未读结果，点击事项进入来源会话或子代理。离线与同步不完整时显示范围提示，数量只覆盖已知状态。待办中心不会自动批准、重发或继续任务。

### 审批与问题

审批卡片显示命令、原因、目录或请求权限，请核对后选择。额外权限请求可按网络与文件范围选择授权，以及仅本轮或整个会话有效。

同步问题在问题卡片回答，普通聊天草稿保留。提交失败可原位重试；普通答案草稿保存在浏览器，私密字段不保存。异步答案进入持久化队列，刷新或重连后检查并继续发送。MCP 信息请求支持表单或链接确认，链接需由用户打开、完成后确认；不支持的结构可拒绝或取消。

## 跟进执行与子代理

对话展示消息、命令、文件修改、思考和计划。成功结束后默认收起执行过程，失败或中断保留提示；可在「设置 → 通用 → 会话交互」关闭自动收起。用户消息、最终回答和轮次状态始终可见，过程和日志可手动展开。

服务端记录了步骤时间时，工具条目显示耗时，执行中的步骤显示已用时；旧历史缺少时间时不推算。模型或提供方不可用时，错误保留原文并补充恢复建议，不会自动换模型、换提供方或重复发送。

图片生成支持内嵌结果和环境中的保存文件。仅返回文件 ID 且没有可读取图片时，显示「图片已生成，暂无法预览」。展开「图片生成记录」可查看生成 ID、参考图片路径与 SHA-256；这些是生成时的读取记录，当前路径里的文件可能已经变化。

向上滚动离开底部会暂停自动跟随，点击回到底部恢复。右侧问题导航可预览并跳转到用户消息，跳转后可返回原阅读位置。Markdown 支持表格与代码高亮；Mermaid 可切换源码、复制和放大，渲染失败时保留源码。

「查看子代理」显示代理状态与只读执行详情，可在抽屉中查看下级代理。审批与问题由实际请求会话处理，详情内可回答或审批。子代理状态不触发页面或系统完成通知。临时会话仅显示当前连接收到的实时活动，其事件范围由服务端决定。

轮次存在文件操作或 diff 时显示「本轮变更」，可查看差异与导出服务端汇总补丁。它代表当前轮次记录；右上角 Git 状态与 Git 面板则反映整个仓库磁盘状态，包含手动及其他会话修改。

## 文件工作区

右侧提供「文件」「搜索」「Git」「工作区」页签，目录跟随当前会话。点击文件在主区域打开编辑器，多文件使用标签页。主区域达到 960px 时可并排查看对话与编辑器，拖动分隔线保存比例，双击或按 Enter 恢复均分；窄屏切换主区域。「返回会话」保留编辑缓冲和阅读位置。

### 浏览、搜索与传输

- `⌘/Ctrl+P` 快速打开文件，支持路径模糊搜索和 `app.ts:20:3` 行列定位，最多 50 项结果。
- `⌘/Ctrl+Shift+F` 搜索磁盘文件内容，支持区分大小写，最多 500 个匹配行；不搜索未保存草稿。Git 项目排除被忽略的未跟踪文件，非 Git 项目按 `.gitignore` 过滤。
- 文件树可浏览被忽略的文件，以灰色区分；Git 状态标记说明修改、冲突及未跟踪状态。可开启跟随编辑器，或从编辑器定位当前文件。
- 支持新建文件／目录、复制路径、插入引用和删除。右键、行尾菜单或 Shift+F10 打开操作。已有目标不会自动覆盖。
- 可批量上传，每个文件最多 8 MB。同名时选择替换、保留两者或取消。下载为单文件，最多 8 MB；文件有未保存修改时可先保存或下载磁盘版本。

### 编辑与保存

桌面使用 Monaco，`⌘/Ctrl+S` 或「保存」写入磁盘；手机只读。保存前检查磁盘外部修改，冲突时保留草稿，可比较、重新加载或另存为。文件接口不提供原子条件写入，避免多个进程同时写入同一文件。

| 默认范围               | 行为                                                     |
| ---------------------- | -------------------------------------------------------- |
| 不超过 1 MB            | 正常编辑，支持语法高亮、Markdown 和 Git 行标记           |
| 超过 1 MB、不超过 5 MB | 纯文本简化编辑，关闭高亮、Markdown 渲染和自动 Git 行标记 |
| 超过 5 MB、不超过 8 MB | 只读查看                                                 |
| 超过 8 MB              | 无法通过当前整文件接口打开                               |

文件超过 20,000 行或单行超过 20,000 字符时也进入简化模式。显式差异比较仍可使用受限的纯文本计算；计算超时会提示。Git 差异默认每个版本最多 8 MB。

「设置 → 工作环境 → 文件与差异」可调整普通、编辑、查看和差异上限，范围为 0.25–8 MB；普通 ≤ 编辑 ≤ 查看，差异 ≤ 查看。配置保存在当前浏览器。编辑内容超出上限时保留撤销历史，缩减内容或提高上限后才能保存。

「比较未保存更改」对比读取／保存基线与草稿；「比较磁盘内容」用于核对外部修改。右侧草稿可继续编辑，返回后保留撤销记录。Markdown 文件可编辑、预览或分屏，预览显示未保存内容；相对链接按该文件目录解析，本地图片显示占位提示。

Git 行标记比较暂存区与编辑缓冲，包含未保存内容。Git 页的 Diff 标签为只读磁盘快照：未暂存比较暂存区与磁盘，已暂存比较 HEAD 与暂存区，未跟踪以空文件为基线。临时 Diff 标签可固定；「打开当前文件」回到编辑缓冲，不替换已有草稿。Git 工具可导出补丁和列出工作树，修改仓库的操作使用外部终端或其他 Git 工具完成。

## 项目与会话工具

「工作区」集中显示项目目录、常用命令、预览、当前会话工具和项目默认设置。配置按环境、服务地址和目录保存，每个环境最多 100 个项目；删除配置不会删除磁盘目录。项目说明和默认模型仅用于新建会话。

测试、构建和开发命令通过所选环境的 `command/exec` 使用 `/bin/sh -lc` 执行，受环境权限约束。运行前核对目录与命令；执行后在底部「项目命令」查看流式日志、发送标准输入或停止。测试与构建超时为 10 分钟，开发命令为 24 小时。每个连接同时管理一项项目命令；断线或刷新后结果可能未知，核实后再运行。预览 URL 需显式配置 HTTP(S) 地址，打开不表示服务已就绪。

### 项目终端

桌面选中已连接的环境与当前项目后，点击顶部「打开终端」即可使用只读交互 shell：当前项目没有任何终端记录时，工作台自动准备首个 shell，无需配置、另起 app-server 或更换 shell。已有记录时仅展开面板，不重建 shell、接管旧进程或重跑命令。可按 `⌘/Ctrl+反引号` 切换面板显示，使用「新建终端」增加标签；目录菜单中的「在此目录新建终端」以该目录启动 shell。

终端提供通用 POSIX shell，通过执行环境的文件只读策略限制写入，并未按 Git 命令白名单过滤输入。常用场景包括：

| 场景             | 示例                                                          |
| ---------------- | ------------------------------------------------------------- |
| 浏览目录与文件   | `pwd`、`ls -la`、`cd src`、`find . -name '*.ts'`              |
| 读取、搜索与统计 | `cat README.md`、`head`、`tail`、`grep`、`wc`；管道可组合使用 |
| 持续查看日志     | `tail -f app.log`，按 `Ctrl+C` 停止查看                       |
| 检查基础环境     | `uname -s`、`command -v git`；已安装工具的版本查询            |
| 查询 Git         | `git branch`、`git status`、`git log`、`git diff`、`git show` |

`rg`、`jq`、Node、Python 等额外工具是否可用取决于所选设备已安装的程序和 app-server 的 PATH；终端不会自动安装工具、加载 `.env` 或激活虚拟环境。`ps`、`lsof` 等系统诊断也可能受平台与沙箱权限限制。部分看似查询的命令会写缓存，不能保证所有工具都在只读环境中正常运行。

终端固定为文件只读且禁用网络。`curl`、`ping`、SSH 和远程查询可能需要网络，因此当前也受限；文件只读本身不等于网络只读查询，禁网是当前独立的策略。`git checkout`、`git add`、`git commit`、安装依赖、写文件或重定向写入会被服务端拒绝；`sed`、`find` 等工具是否写入取决于参数，写入参数同样受限制。测试、构建和开发仍通过独立的「项目命令」运行，遵循所选环境权限。

终端按执行环境、服务地址和项目目录归属，不绑定某条聊天。同一项目切换聊天时保留终端；切换项目或环境后仅显示目标项目的终端。提示符显示 shell 当前完整目录，例如 `/demo/atlas-web/src $`，执行 `cd` 后自动更新。`cd` 不改变终端所属项目，面板中的项目目录和启动目录也不代表 shell 当前目录。

「收起终端」只隐藏面板，进程继续运行。每个终端标签右侧提供关闭按钮：已确认空闲的终端直接关闭；前台／后台任务运行中或活动状态尚未确认时，先提示可能中断任务。只有收到服务端退出结果才移除正在关闭的标签。已退出的终端可直接移除；离线或刷新后状态未知的记录只允许明确选择「仅移除记录」，不声称终止原进程。关闭其他标签不会切换当前终端。

终端支持交互输入、`Ctrl+C`、复制粘贴、调整高度和最大化。手机只显示输出，不能新建、输入或关闭活跃终端。测试、构建、开发按钮与终端共享底部面板，分别显示在「项目命令」和「终端」中。

终端区分 shell 空闲与命令执行状态。状态来自 shell 提示符标记、提交的输入及最近一次后台任务检查，不通过日志是否安静来判断。自定义提示符覆盖集成、连接中断，或多行粘贴等输入无法可靠匹配执行状态时，保留待确认状态；后台任务完成可能需要再次返回 shell 提示符后更新，不包含已经脱离终端的进程。

终端常态仅保留一行工具栏，环境名称及锁形「只读」标识始终可见；点击环境标识可查看完整目录与只读、禁用网络详情。选中输出后才显示复制和添加到对话的图标。最大化会临时隐藏对话与编辑器，恢复后保留草稿和编辑内容。项目命令默认展示最新记录，历史通过下拉切换，目录与进程信息可在「命令详情」查看。

当前目录以绿色提示，并随浅色／深色主题调整配色；普通命令输入与文本输出使用正常前景色。终端保留工具输出的 ANSI 颜色，macOS 的 `ls` 默认开启目录颜色，Git 与搜索结果是否着色仍由工具自身配置或参数决定，不会强制给管道内容添加颜色。`NO_COLOR` 环境变量存在时关闭内置颜色。当前 POSIX shell 不提供输入命令的实时语法高亮，`cat` 也不会自动为代码内容添加语法高亮。

终端使用 POSIX `/bin/sh` 交互 shell，面向提供该路径的 macOS/Linux 环境。内置启动适配保留 PATH 中已有的 Git；仅命中 Apple `/usr/bin/git` shim 时寻找实际 Git 二进制，避免该 shim 引发的 `confstr`／`xcrun` 缓存警告。Git 可选索引写入已关闭，真实命令错误仍正常显示。只读策略与聊天审批设置分开；启动失败时不自动改用更宽权限。

选中终端文本后点击「添加到对话」，只把所选内容及环境、项目和启动目录追加到当前聊天草稿，不自动发送，也不覆盖原草稿。终端输出只在当前页面内存保留，回滚记录有上限；早期内容清理后会显示提示。

对话中的完整单行 shell 代码块提供「填入终端」，先进入待填入区，可核对或编辑。再次点击「填入终端」只把文字写入当前终端输入，不发送换行；按 Enter 才执行。多行命令和生成中的代码块不提供该入口。

断线或刷新后不能重新接管原终端。工作台仅恢复终端记录并标为待核实，不自动重建 shell 或重跑命令；请先核实原进程状态。页面存在活动终端时会启用离页提醒，提醒不保证进程在离页后继续或停止。

发送首条消息后，可使用「当前会话」工具：

| 工具           | 行为                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| 会话目标       | 设置目标内容、状态和可选 Token 预算；保存可能让服务端继续执行，替换目标会重置用量记录                        |
| 代码审查       | 审查未提交修改、相对基准分支的差异、指定提交或自定义范围，结果进入当前对话                                   |
| 参考资料       | 保存名称与链接／路径、查看归属、插入输入框；工作台创建的引用可移除                                           |
| 会话用量与费用 | 手动读取当前会话的原生美元用量、估算金额、积分和模型分组；未知值不显示为零，各类金额不相加，不代表最终账单   |
| 当前会话 Hooks | 展开后查询已加载会话及其执行环境的 Hooks，展示来源；记录面板打开期间收到的本会话执行事件，不获取会话写入权限 |
| 本地诊断包     | 显式导出 ZIP 到所连接环境的主机，运行日志默认不包含；可另行下载，不上传反馈                                  |

任务执行期间可查看工具和导出诊断包；目标、审查和参考资料的修改需等待任务结束。

费用数据按需刷新，不自动轮询；断线、账户或工作区改变会清除旧用量。当前服务端未提供对应接口时，界面说明原因，其他会话功能仍可使用。

诊断包可能含会话与项目资料，分享前请自行检查。保存路径必须是环境主机上尚未使用的绝对 ZIP 路径；远端路径不是浏览器所在电脑的路径。导出不触发任务执行，可在任务运行时操作。断线或超时后保留待核实路径，不自动重新导出；先尝试取回原文件，再用新路径发起另一份导出。路径状态保留于当前页面内存，关闭页面前请记录。网页下载最多 8 MB，超出时请直接从环境主机取回；文件不会自动删除。

## 账户、配置与集成

「设置 → 工作环境」先选择设备，再选择对应面板。所有操作针对所选环境，有当前会话时使用其目录。

| 面板       | 用途与影响                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| 连接与账户 | 管理连接、设备码／浏览器／API Key 登录、取消登录和退出；远端建议设备码，退出影响同一环境的其他客户端 |
| 账号与用量 | 查看账户、额度组、重置时间和个人支出上限；打开及手动刷新时读取，通知到达后同步，不定时轮询           |
| 模型与权限 | 管理浏览器新会话偏好、设备默认模型与审批，查询指定绝对目录的项目生效配置和受管策略                   |
| MCP        | 查看连接、认证和工具状态，打开 OAuth 链接，重新加载磁盘配置                                          |
| 技能       | 查看、启停技能与加载错误；额外目录替换当前 app-server 进程整组目录，可能影响其他客户端，不写入磁盘   |
| Hooks      | 只读查看事件、处理器、启用与信任状态及加载错误                                                       |
| 应用       | 查看已安装与可用连接器、工具摘要，插入应用提及到草稿；安装和授权在对应服务完成                       |

服务端提供可用额度重置机会时，可查看详情并确认使用；不会自动消耗，失败不会自动重试，操作后重新读取用量。时间使用浏览器本地时区，缺失字段不推算。

账户状态可识别 Google Cloud，并在服务端提供时显示 ChatGPT 当前工作区。账户类型展示不代表工作台提供该类型的登录或多账户切换流程。

接口能力面板区分未探测、支持、不支持、认证、策略、参数和临时故障。仅方法不存在时缓存为不支持；重连或手动清除记录可重新尝试。写操作需要明确执行，不通过读取结果推测可用性。

## 外观、通知与数据

「设置 → 通用」提供浅色、深色和跟随系统。桌面面板可调整与折叠，窄屏使用抽屉。标签页标题跟随当前会话与执行状态；图标优先显示尚未查看的成功结果，其次显示执行中。查看对应主会话可清除未读提示，关闭通知不会清除，刷新会重置未读提示。

| 数据                                                 | 保存位置与生命周期                                         |
| ---------------------------------------------------- | ---------------------------------------------------------- |
| 会话历史、任务状态、分区和账户                       | 所连接环境的 Codex app-server                              |
| 环境配置、语言、主题、模型偏好、布局、收藏与项目配置 | 当前浏览器本地存储                                         |
| 未发送会话、输入文本、引用、普通问题草稿             | 当前浏览器，按环境与服务地址等范围隔离                     |
| 待发送队列及其中的附件                               | 当前浏览器 IndexedDB，恢复后暂停                           |
| 未保存文件及基线                                     | 浏览器恢复存储，小文件使用本地存储，较大内容使用 IndexedDB |
| 普通输入草稿中的图片                                 | 当前页面内存，恢复后需重新添加                             |
| Bearer Token、API Key 表单和私密问题字段             | 当前页面内存，不持久化                                     |
| 已上传附件文件                                       | 执行环境的附件目录，移除引用不删除文件                     |

编辑恢复按环境与地址最多保存 20 个文件，恢复后不会自动写入磁盘，也不恢复撤销历史或只读 Diff 标签。较大草稿停止输入约 400ms 后异步写入 IndexedDB，页面会显示状态；存储失败或超限时请保存或复制内容。离开页面前确认恢复副本已写入或直接保存到磁盘。

浏览器可能在离开有未保存内容的页面时要求确认。清除站点数据会删除本地配置、草稿和队列，但不会删除环境中的历史、认证或已上传附件。恢复副本不能代替磁盘保存，也不提供多标签页协同编辑。安全与隐私说明见 [SECURITY.md](../SECURITY.md)。
