# 使用指南

## 工作环境与连接

先按 [README](../README.md) 启动网页和本机服务，再在「设置 → 工作环境」填写实际监听地址。开发模式需手动启动 app-server；生产模式的 `npm start` 会启动本机 app-server，或复用已有服务。修改端口时，同时修改终端命令和连接配置。已有服务占用网页端口时，程序不会停止它或自动改用其他端口。

连接远端开发机时，在远端终端启动服务：

```sh
codex app-server --listen ws://127.0.0.1:4500
```

在本机另一个终端建立 SSH 转发：

```sh
ssh -N -L 14500:127.0.0.1:4500 dev-box
```

在「设置 → 工作环境」点击「添加开发机」，填写 `ws://127.0.0.1:14500` 并连接。`dev-box` 替换为自己的 SSH 主机；新会话的工作目录填写远端路径。转发终端需保持运行，app-server 输出在启动服务的终端查看。

本机和多个开发机可同时连接。侧栏顶部显示环境名称，首次使用默认查看当前环境。环境标签能完整放下时直接展示，放不下时自动使用下拉选择，包含「全部环境」并保留连接状态标记；判断随侧栏实际宽度、名称长度与字号变化，两个环境也可能使用下拉，较宽侧栏可直接展示更多环境。切换控件不会改变筛选范围或列表高度。环境筛选不切换当前对话或中断任务，新建会话优先使用筛选环境。「项目／最近」右侧工具栏常驻「定位当前会话」图标，悬停可查看说明；当前会话被筛选、折叠隐藏或滚出可见区域时图标高亮，定位后恢复普通状态。点击后回到它所在的范围、展开所属项目并滚动到会话。定位入口不会增加或移除列表上方的提示行，没有当前会话或当前会话已归档时不可用。断开的环境配置保留在设置中，有缓存时可继续查看已加载历史，状态显示为待同步；重新连接后更新。

需要认证的服务可在连接表单填写 Bearer Token。Token 不保存到浏览器存储，关闭表单或切换设置分类后清空；重新加载页面后的连接需要重新填写。

## 会话与历史

「新建会话」先创建未发送草稿，第一条消息发送时才创建服务端会话。草稿可切换、重命名和删除。提交后输入框立即清空，消息显示在正文中，并依次提示正在创建会话、正在发送；创建期间可以继续编辑下一条草稿。创建或发送失败时，内容保留在发送记录中，可点击「恢复到输入框」编辑后重试；恢复保留引用和图片，并与已有新草稿合并，不自动发送。发送结果待核实时须先检查会话记录，避免重复提交；创建成功后的重试复用已知的服务端会话。发送记录仅保留于当前页面，尚未确认送达或失败记录未处理时，离开页面会提示。普通输入文本、结构化引用和未发送会话的名称、目录及基本模型设置保存到当前浏览器，按环境与服务地址隔离；刷新后恢复，不自动发送。图片内容不持久化，恢复时会提示重新添加。存储不可用或超限时显示警告，内容仍保留在当前页面。

打开已有会话先读取历史，发送时才确认写入能力。其他客户端占用写入时保留输入并提示占用，可通过「重试发送」重新确认。断线后输入保留，发送和停止不可用；重连补读历史，消息和审批响应不会自动重放。终端会话的同步取决于服务端状态更新和历史落盘，状态信息不足时显示「执行状态待确认」。

侧栏提供「项目」和「最近」两种视图。「项目」按环境与项目分组，收藏项目优先，其余项目按组内最新会话活动时间倒序排列；时间相同时按环境名和项目名排序。项目内的会话也会随创建或更新即时重排。列表原本在顶部时，重排后继续保持顶部；已经向下滚动时，尽量保持正在浏览的会话在屏幕上的位置。项目可分别折叠或一键折叠／展开全部项目。「最近」按会话实际活动时间倒序排列，并按今天、昨天和更早分组；点击或切换会话不会改变排序，行内时间与排序使用同一时间。新会话发送首条消息后会立即更新为正式会话，切换环境或视图即可继续查看，无需刷新。视图、环境范围、状态筛选、项目展开状态和列表滚动位置保存在当前浏览器，返回对应范围时恢复。

进入某个环境范围后，侧栏自动补齐该范围的历史会话摘要，显示加载进度，无需手动加载下一页。「项目」视图默认每个项目展示前 5 条会话，可点击「展开其余 N 条会话」立即查看全部已加载摘要，再点击「收起为 5 条」恢复紧凑列表；展开只改变展示范围，不重新请求正文。搜索或链接打开较早的会话时自动展开对应项目并定位。展开后的项目标题在滚动时保持可见，可随时折叠整个项目。「最近」视图仍展示全部已加载会话。完整对话正文在打开会话时读取。加载失败时保留已经显示的会话，并提供重试入口。「会话状态」可筛选全部会话、待处理、运行中或未读结果；待处理包括待审批、待回答、暂停队列和失败或待核实的会话。离线环境保留缓存和待同步说明，不将旧的运行状态当作当前运行中。

「搜索会话」默认使用当前侧栏的环境范围，可在搜索窗口选择其他环境或「全部环境」。不输入关键词时显示最近访问和已加载会话；输入完整 Session / Thread ID 可精确定位历史，无需先把该会话加载到侧栏。普通关键词同时匹配本地已加载会话和草稿的标题、摘要、工作区路径与已加载对话，并向所选已连接环境搜索服务端历史标题；结果注明匹配来源，历史结果滚动时继续加载。服务端标题搜索区分大小写，未加载的正文不在搜索范围。离线环境只搜索本地已加载内容，未缓存的历史需连接后查找和打开。

每条会话右侧和当前会话标题栏都有「会话操作」菜单，也可右键打开。菜单提供收藏、重命名、分叉、复制 Session ID、复制对话为 Markdown、复制最终总结和导出。项目操作菜单也可收藏项目；收藏的会话或项目优先展示。收藏仅保存在当前浏览器，按环境与服务地址隔离，不写入服务端或跨设备同步。分叉和回滚需要等待当前执行结束。导出包含用户与助手消息及会话信息，操作日志仍在页面中查看。

归档会话会从普通列表移除，页面底部提示可直接「撤销」。归档当前会话时保留已经打开的正文供只读查看，恢复后才能继续发送；可从归档提示、当前会话提示或会话菜单恢复。其他归档会话可从「导航选项 → 已归档的会话」或「设置 → 已归档的会话」选择环境后恢复。删除有文字、附件或技能的未发送草稿时会要求确认；草稿删除后无法恢复。

当前会话链接使用 `/?env=<环境ID>&session=<会话ID>`，支持刷新、直接打开和浏览器前进／后退。`env` 对应浏览器中已配置的环境 ID；远程链接需要预先配置指向同一服务的相同环境 ID。链接不携带连接地址或凭据，未发送草稿只能在保存了该草稿的浏览器和对应环境中恢复。

分区用于在环境内分类会话。未使用分区时，侧栏默认收起分区入口，可从「导航选项 → 分区筛选与管理」展开。分区下拉框跟随环境范围；「全部」环境视图会标明分区所属环境。选择分区即可筛选会话，选择「管理分区…」可打开管理弹窗；会话菜单中的「移动到分区」可调整归属。弹窗默认选择侧栏当前环境，也可切换环境管理分区；切换时清空未保存的编辑状态。分区属于所选环境的服务端数据，所有客户端共享，与当前浏览器的收藏分别保存。

会话菜单中的「永久删除」需要明确确认，会删除该会话及其后代子代理会话和历史，不能恢复；仅想从普通列表隐藏时使用归档。消息中的回滚操作以所选轮次为边界，执行前需要确认，当前任务运行时不能回滚。

## 会话工具

打开右侧「工作区 → 当前会话」可使用目标、代码审查与参考资料。未发送草稿尚无服务端会话，先发送首条消息后再操作；任务运行时可查看，修改需等待任务结束。

- **会话目标**：读取或设置目标内容、状态和可选 Token 预算，也可清除目标。保存目标可能让服务端继续执行；更换目标内容会重置目标用量记录，预算与状态以服务端返回为准。
- **代码审查**：选择未提交修改、与基准分支比较、指定提交或自定义说明，在当前会话启动审查，结果显示在对话中。
- **参考资料**：保存资料名称与链接或文件路径，查看资料的所属会话，或移除本工作台添加的引用。这是会话关联信息，不会上传文件、读取路径内容或把链接内容自动加入下一条消息。其他来源的资料按只读方式显示。可点击「插入输入框」将资料名称和位置追加到草稿，保留原有引用和附件；这不表示模型已读取资料，也不会自动发送。文件引用仍可使用 `@`。

## 输入、模型与附件

| 操作                           | 快捷键或入口                             |
| ------------------------------ | ---------------------------------------- |
| 发送；执行中遵循引导／排队偏好 | Enter                                    |
| 换行                           | Shift + Enter                            |
| 立即引导当前执行轮次           | ⌘ + Enter / Ctrl + Enter，或「立即引导」 |
| 搜索会话                       | ⌘ + K / Ctrl + K                         |
| 引用工作目录文件               | 输入 `@` 后选择文件                      |
| 引用技能                       | 输入 `$` 后选择技能                      |
| 查看快捷命令                   | 输入 `/`                                 |

补全列表用上下键选择，Enter / Tab 确认，Escape 关闭。中文输入法确认候选时不会发送。文件和技能引用是完整标签，Backspace / Delete 一次删除整个标签；在输入框内复制粘贴保留引用，复制到外部应用时输出完整文件路径或技能名称。编辑器保留文本与段落，不保留外部粘贴内容的字体、颜色等排版。

发送后的用户消息保留输入中的单次换行，并按 Markdown 展示引用、列表和代码。引用段落之后空一行可开始普通段落。

立即发送或引导当前任务时，消息会先显示「正在发送」，收到服务端消息记录后自动合并，不需要等待模型回答。排队消息仍显示在待发送队列中。发送失败或连接中断时，会保留输入并显示投递状态；结果待核实时不会自动重发，请先核实会话记录再决定是否重新发送。关闭发送记录只移除本地提示。

输入区可选择服务端提供的模型、推理强度、审批策略和服务档位。「设置 → 工作环境 → 模型与权限」统一管理模型设置：本浏览器的新会话偏好适用于所有设备，可选模型列表来自当前所选设备；设备默认模型写入该设备的用户配置。通过新建会话窗口创建任务时，已保存项目的显式模型优先于浏览器偏好，输入区仍可调整；选择「跟随设备默认模型」时，新会话不指定模型，由服务端按配置决定。已有会话保留自己的模型设置。输入区默认「沿用当前审批设置」，展示服务端已确认的审批值；本地未生效的选择标为「下次」。只有显式选择才发送覆盖，此项不控制沙箱。服务端当前有效策略未能核实时不会推测其值。覆盖影响当前及后续轮次，改回「沿用当前审批设置」不会撤销已经发出的覆盖；排队保留入队时的选择，立即引导沿用当前轮次的配置。

服务档位选项由当前模型目录提供；未知档位或尚未获取的状态不会显示成标准档位。显式选择在新轮次发送后应用到会话及后续轮次，队列保留入队时的选择，立即引导不改变正在执行的轮次。问题卡片回答沿用会话设置，不应用输入区尚未发送的选择。上下文用量未获取时显示「上下文：暂无数据」，不表示上下文为空。

图片支持文件选择、粘贴和拖放，点击缩略图可预览。支持 PNG、JPEG、WebP、GIF，每张不超过 5 MB，最多 4 张，编码后合计不超过 10 MB。发送图片需要模型声明支持图片输入；批量读取失败会逐项报错并保留成功的图片。

执行中可继续输入，也可停止当前任务。等待审批或回答问题时，先处理请求；此时仍可停止当前执行。发送成功只清除已提交的输入，提交期间新写的内容继续保留。

问题卡片与普通聊天输入框用途不同。同步问题通过「前往问题卡片回答」定位并提交，普通消息草稿继续保留；提交中保持表单和阅读位置，失败可原位重试，回复发送成功后直接收起，不再等待额外确认或保留回答摘要；发送失败时保留卡片以便重试。若焦点仍在卡片内，收起后返回输入框。异步问题通过卡片回答，执行中会补充到当前任务，空闲时开始下一轮；普通追问不会自动关闭旧问题。同名问题按各自身份关联答案。忽略的问题可通过「恢复已忽略问题」重新显示。

普通问题答案支持多行输入，未提交草稿按环境、会话和问题保存在浏览器中；私密字段不保存。异步答案提交后进入持久化队列，重连或刷新恢复后请检查并继续发送。较旧服务端若不回传答案关联标识，同名问题无法可靠自动收起，会保留供用户核对。

额外权限请求会显示网络权限和文件访问路径，可按网络／文件两组选择授权，并选择仅本轮或整个会话有效。拒绝不会授予任何额外权限。MCP 补充信息请求支持标准表单和链接确认；链接需由用户打开并完成后确认。不支持的表单结构会明确提示，可拒绝或取消，不会自动提交。

「设置 → 工作环境 → 连接与账户 → 账号与用量」显示该环境的账户、用量窗口、重置时间与更新时间，打开面板时读取一次，并支持手动刷新；不定时轮询，收到用量更新通知后合并刷新完整快照。登录、退出或账号变更后会同步一次。刷新期间保留已有数据和更新时间。服务端不支持或暂时无法读取时会显示原因，不影响连接；重置时间不代表任务必然能够恢复，队列仍按原有规则由用户继续。配置警告、运行警告和模型切换提示显示在当前环境顶部，可关闭。

套餐与登录方式来自账户接口；用量按服务端返回的额度组展示已用比例、重置时间、额外额度及个人支出上限。时间采用浏览器本地时区，缺失字段不推算。

可用重置次数为零或未提供时不显示重置区域。服务端提供可用重置次数和明细时，可查看有效期并选择「使用此重置机会」，确认后消耗一次机会。只有可用、未过期且类型受支持的明细允许使用。仅有次数、明细尚未提供时，可确认由服务端选择一个可用机会；不自动消费。操作后重新读取用量，分别提示成功、已处理、无可重置窗口或无可用次数；失败不自动重试，同一次重试复用幂等标识。刷新失败时需先成功刷新用量再操作。

## 账户与环境工具

「设置 → 工作环境 → 连接与账户」中的「账号与用量」操作所选环境的 Codex 账户，提供设备码、浏览器和 OpenAI API Key 登录，也可取消登录或确认退出。远端环境建议使用设备码。网页的 Bearer Token 用于连接服务，与 Codex 账户 API Key 是两种独立凭据；API Key 表单不保存在浏览器存储，登录请求由所选 app-server 处理。退出会影响同一环境的其他客户端和后续任务。

设置保留「通用」「工作环境」「已归档的会话」三个一级分类。「通用」包含显示偏好和会话交互。「工作环境」先选择设备，再通过下拉框切换「连接与账户」「模型与权限」「工具与集成」「配置迁移」；连接、账号与用量归为一组，模型、设备默认设置与项目配置查询、受管策略归为一组，MCP、技能、Hooks 和应用归为工具与集成，迁移单独提供入口。工具与配置面板点击「刷新」后加载，单个功能读取失败不会使连接断开。有已选会话时使用它的工作目录；切换环境后只操作新选中的服务。

| 面板                             | 用法与影响                                                                                                                                                                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| MCP 服务                         | 分页查看连接状态、认证状态和工具数量；OAuth 登录返回授权链接，需在浏览器完成。重新加载从磁盘读取 MCP 配置并请求服务端刷新，不能保证每个服务器立即连接成功；启动与登录结果会显示在面板中。                                            |
| 设备默认设置、项目配置与受管策略 | 查看模型、提供方、审批、沙箱及部分受管约束，不展示完整配置或凭据。可明确保存默认模型或默认审批策略到该环境的用户配置；项目、会话或受管配置仍可能覆盖它。设备配置与同页的浏览器偏好分别保存、分别生效；已有会话也可能保留自己的设置。 |
| 技能                             | 按工作目录查看技能与加载错误，并启用或停用技能。额外技能目录填写绝对路径，每行一个；「应用额外目录」替换当前 app-server 进程的整组额外目录，留空会清除，不写入磁盘，可能影响使用同一服务的其他客户端。                               |
| Hooks（只读）                    | 查看事件、处理器类型、启用状态、信任状态、来源路径与加载错误；工作台不执行或编辑 Hook。                                                                                                                                              |
| 已安装应用、可用应用             | 查看已安装连接器的启用与可调用状态，分页查看可用应用及工具摘要。有已选会话时可「插入应用提及」到草稿，由用户检查后发送；这不执行工具，也不安装或授权应用。                                                                           |
| 外部配置迁移                     | 在当前会话目录探测迁移项，默认不扫描主目录；可明确勾选「包含用户主目录」。探测后逐项选择，再点击导入；导入会写入所选环境的配置或文件。面板显示进度、成功／失败结果与迁移历史，不会自动重试。请求失败或断线后先刷新历史核实结果。     |

不同 app-server 版本、账户和受管策略提供的能力不同。较新的目标、分类、应用和迁移接口可能被拒绝或不受支持，面板会保留对应错误；应用接口仍可能需要服务端允许的实验能力。工作台在初始化时声明实验 API 兼容能力，以访问应用等接口；这不会开启服务端实验功能开关、安装插件或绕过受管策略。升级服务后可重新连接并刷新对应功能。接口接入范围见 [App-server 覆盖范围](app-server-coverage.md)。

「工具与集成」中的接口能力面板显示当前连接实际调用的结果，区分未探测、支持、不支持、认证、策略、参数和暂时故障。只有方法不存在（`-32601`）才缓存为不支持并阻止重复调用；可清除记录后手动重试，重连也会重置。不从读取接口推断写入接口可用，也不会为了探测而执行写操作。

## 待发送队列

侧栏「待办中心」汇总所有环境当前已知的待审批、待回答、失败或待核实、暂停队列和待查看结果，并显示待办数量；其他环境有事项时也会提示。待办中心按环境说明同步状态：未连接环境显示「待办状态待同步」或已缓存的已知数量，可点击「连接环境」；同步中或同步不完整时说明当前数量仅覆盖已加载状态，不把未知状态显示成 0 项。

每类事项提供处理说明，并显示来源环境与会话，点击后到来源会话或子代理详情处理；未提供会话的请求会说明无法定位。完成通知关闭后，未读结果仍可在这里找到，查看会话后清除；未读结果随页面刷新重置。待办中心不会自动审批、重发或继续队列，也不会读取未加载的全部对话正文来推断待办。

在「设置 → 通用 → 会话交互」选择执行中发送的默认行为：排队（默认）或引导当前任务。设置保存在当前浏览器并立即生效，Enter 和主发送按钮保持一致。输入区提供另一种方式的单次操作；⌘/Ctrl+Enter 始终引导，⌘/Ctrl+Shift+Enter 始终排队，Shift+Enter 换行。已有队列不会因设置变更而改变。若发送时轮次已结束或当前轮次无法定位，沿用会话状态检查，正常发送或入队，不向过期轮次盲目发送。

执行中默认按 Enter 加入队列，可在通用设置中改为引导；排队任务会在当前任务完成后按顺序逐条启动下一轮。每项任务保存文字、文件／技能引用、图片、模型和审批配置。任务菜单支持编辑、删除、移到最前和立即引导，编辑任务不覆盖输入框里的另一份草稿。

停止、失败、刷新或重连后，队列暂停；检查任务后点击「继续队列」。页面关闭期间不会继续发送。显示「发送结果待核实」时，先查看服务端历史：已发送则删除该项，确认未发送后再允许重试。

队列保存在当前浏览器的 IndexedDB，并按环境、服务地址和会话隔离。浏览器不支持 IndexedDB 时仅保存在页面内存；Web Locks 可用时协调多标签页调度，缺少该能力时不能保证跨标签页协调。

## 执行详情与子代理

对话按时间顺序展示消息、命令、文件修改、思考和计划。默认在完成后收起执行过程，入口位于过程之前；设置中的「完成后自动收起执行过程」可更改此偏好，用户手动展开的选择会保留。失败、中断及异常操作保留可见提示。用户问题、最终回答和轮次状态不折叠；没有内容的已完成思考记录不显示。每条回答可独立复制，最终回答有轻量标识。命令标题优先使用读取、搜索等操作描述，未知命令显示简短预览，展开可查看完整命令和日志。 连续同类活动从第一条起归入稳定批次；只有一项时直接显示具体操作，点击一次查看详情，多项才显示汇总入口。读取、搜索及文件修改默认收起详情，持续命令和同名工具调用在执行时展开。已展开的日志保留到下一类消息到来且本批全部结束，不因单条命令完成或短暂空档反复收起。已展开过程中的手动查看会保留操作、批次和整轮过程；过程收起时只展示需关注条目，展开这些条目的详情不会展开整轮过程。完整规则见[会话动态更新](conversation-updates.md)。

长问题默认折叠，点击「展开完整问题」查看全文。会话右侧圆点按用户问题顺序导航，悬停或键盘聚焦可预览标题，点击跳转；高亮长点表示当前问题。圆点超出固定高度后可滚动或用上下按钮翻阅，也支持方向键及 Home / End，底部显示当前位置与总数。跳转后可返回原阅读位置。主动向上滚动会话并离开底部时暂停自动跟随，点击回到底部按钮恢复。在任务日志或工具进度内部滚动不会暂停会话跟随；滚动传递到会话后才按会话位置判断。

Markdown 支持表格、代码高亮与代码复制。Mermaid 代码块可切换图表／源码、复制源码和放大查看；语法错误时保留源码并提供重试。

输入区「查看子代理」提供状态列表，选择代理后打开只读详情；下级代理在同一抽屉内导航，主会话保持可用。审批归属于实际请求的会话。子代理的完成、问题和审批不弹出页面或系统通知，等待确认会显示在子代理入口，打开详情后仍可回答或审批；主会话通知保持正常。临时会话没有持久化历史，只能展示当前连接收到的实时活动；能否收到子线程实时事件由服务端决定。

每轮底部仅在有文件变更记录或非空 diff 时显示「本轮变更」，默认折叠。展开后通过文件列表选择差异，新增和删除行分别着色并展示行数；操作记录的行数为累计值，不是最终净变更。操作菜单可导出服务端记录的本轮汇总补丁；只有文件操作记录时不伪造汇总补丁。没有变更的普通问答不显示此区。最终回复和命令日志仍在原会话位置查看，会话 Markdown 导出保留在会话菜单。历史文件记录不代表整个会话的累计净变更，未完整加载时会提示范围。

右上角显示当前 Git 分支和「改动 N 个文件」或「工作区干净」，点击打开项目面板的 Git 页。统计包含已暂存、未暂存、未跟踪和冲突文件，同一文件只计一次；这里是整个仓库工作区的实时状态，包含手工修改和其他会话的修改。读取失败或连接断开会明确显示状态，不以会话记录的旧分支代替实时结果。

项目面板提供四个页签：「文件」浏览、按名称搜索和编辑项目文件；「搜索」查找项目文件内容；「Git」查看仓库状态、差异及只读工具；「工作区」整合当前项目、当前会话和项目默认设置。工作区目录始终跟随当前会话；常用命令显式使用该目录，切换会话后同步切换，不沿用之前选中的其他项目。

按 `⌘ / Ctrl P` 或点击顶部「快速打开文件」按文件名／路径模糊查找；上下键选择，Enter 打开，Esc 关闭。未输入时显示当前项目已打开的文件；可在查询末尾追加 `:行号:列号` 定位，例如 `app.ts:20:3`。最多显示 50 个结果。

按 `⌘ / Ctrl Shift F` 或点击顶部「搜索文件内容」打开项目内容搜索。输入普通字符串后按 Enter，可切换「区分大小写」；结果按文件分组，显示匹配行和高亮片段，点击跳转。搜索读取所连接环境的磁盘内容，不包含编辑器未保存的修改。Git 项目先获取已跟踪及未被忽略的未跟踪文件；非 Git 项目先按 `.gitignore` 规则过滤目录。随后分批搜索并逐批展示结果，最多显示 500 个匹配行；取消时保留已找到的结果，清空输入则清除结果。超限或跳过文件时会提示。搜索优先使用环境中的 `grep`，不可用时以有限并发通过文件接口读取匹配，无需安装 `rg`。

「工作区」依次显示当前项目目录、常用命令与预览，当前会话的目标／参考资料／审查，以及默认折叠的「项目默认设置」。项目说明和默认模型只用于新建会话，不修改已有会话。其他目录仍在运行或结果未知的命令会标为「其他项目运行」，保留停止和核实入口。

文件树保留被 Git 忽略的文件和目录，并用灰色文字显示，仍可展开、打开与管理。忽略状态由 Git 批量判定，包含嵌套 `.gitignore`、例外规则和全局忽略；已被 Git 跟踪的文件不会仅因匹配忽略规则而变灰。

文件树与搜索结果显示 Git 状态标记：`M` 修改、`A` 添加、`D` 删除、`R` 重命名、`C` 复制、`T` 类型变化、`U` 冲突、`?` 未跟踪。悬停或辅助技术可读取暂存区与工作区的具体状态；目录数字汇总子树中有变更的文件数，冲突优先显示 `U`。已删除文件不会伪造为可打开的文件树条目，可在 Git 页查看。顶部、Git 页和文件树共用状态查询，工作目录位于仓库子目录时按仓库根目录映射。

点击文件树或会话中的文件链接后，在主区域打开编辑工作区，右侧仍保留文件树。多个文件以标签切换。内容区域足够宽时，会话与编辑器并排显示，分隔线支持拖动或方向键调整宽度，浏览器记住分栏比例；“专注编辑”展开编辑区域，“并排查看会话”恢复分栏。窄屏使用主区域切换。“返回会话”收起编辑器并保留对话滚动位置、输入草稿与编辑缓冲，可通过“返回文件编辑器”继续工作。链接支持行列定位和行范围，相对路径使用来源会话的目录；历史 diff 中打开的是当前磁盘文件。输入框的文件引用支持 `⌘ / Ctrl` 点击打开，同时保留普通点击选择与删除引用的行为。

桌面使用 Monaco 编辑器，点击“保存”或按 `⌘ / Ctrl S` 写入；手机仅查看。保存前检查外部修改，发现冲突时保留草稿，并提供比较、重新加载或另存为。重新加载和关闭未保存文件需要确认。文件树顶部与刷新同一行的图标用于新建文件／目录；“折叠所有文件夹”可一次收起全部已展开目录，保留根目录文件列表；右键文件或目录可打开复制、引用、删除菜单，也可点击行尾“更多操作”或按 `Shift+F10`，已有目标不会主动覆盖；暂不提供重命名／移动。文件限于 256 KB 以内的 UTF-8 文本，没有完整 VS Code 扩展或语言服务器能力。原生接口没有原子条件写入，仍需避免与其他进程同时写同一文件。

桌面编辑器标题区的“比较未保存更改”使用 Monaco Diff 展示最近读取／保存的基线与当前草稿；冲突提示中的“比较磁盘内容”展示当前已读取的磁盘版本与草稿。差异视图中可继续编辑右侧草稿，切回编辑后保留撤销记录；查看差异不会自动保存，也不代表与 Git HEAD 或暂存区比较。

Markdown 文件提供“编辑／预览／分屏”，预览直接展示未保存内容，支持表格、代码高亮与 Mermaid。预览中的相对文件链接按 Markdown 文件所在目录解析；本地图片暂以提示占位，不通过网页地址误读项目图片。手机可切换源码与预览，保持只读。

普通文件编辑视图的左侧显示 Git 行标记：绿色为新增、蓝色为修改、红色三角为删除。标记比较暂存区与当前编辑缓冲，包含未保存草稿；仅已暂存且草稿与暂存区相同时不显示标记。悬停查看原内容，点击进入差异视图；未跟踪文件以空内容为基线。基线随 Git 状态刷新，输入时仅在本地计算差异。冲突、子模块、非文本或超限基线不显示标记并提示不可用。

Git 页点击未暂存、已暂存或未跟踪文件，会在主编辑区打开只读 Diff 预览标签；点击文件行右侧的“打开当前文件”图标可直接打开工作区文件，并保留已有的未保存草稿。已删除文件的打开图标置灰，仍可点击文件名查看差异。Diff 预览标签使用斜体文件名，连续查看不同文件时复用一个临时标签；双击标签或点击“固定当前标签”可保留它。普通文件编辑使用固定标签，已有草稿不会被预览替换。未暂存比较暂存区与磁盘文件，已暂存比较 HEAD 与暂存区，未跟踪以空文件为基线；重命名使用原路径读取 HEAD，删除以空的新版本展示。快照不包含未保存草稿，可重新加载更新，也可点击“编辑当前文件”返回原编辑缓冲。冲突文件打开当前文件处理。版本内容通过已有 `command/exec` 只读命令获取，不新增协议方法。

会话中的图片附件以等比缩略图展示，多张图片自动换行。点击缩略图或聚焦后按 Enter 可查看大图，点击关闭按钮或按 Esc 返回原位置。输入框、会话附件、工具返回图片和 Markdown 图片使用一致的预览交互；历史本地图片从所属环境读取，读取失败时可重试。输入框内的图片仍可移除，已发送图片用于查看。

## 工作区与验证命令

项目配置按环境、服务地址和目录保存说明、默认模型、测试／构建／开发命令及预览 URL。打开工作区不会自动新建配置；编辑字段才保存，删除本地配置后不会因查看而重新创建。每个环境最多保存 100 个项目；超限或存储失败会提示。删除配置不删除磁盘目录，运行或结果未知的项目暂不能删除。

点击「切换项目／新建会话」，选择已保存项目或填写目录，再进入新建会话窗口确认。确认后创建未发送草稿，应用该项目说明和模型，不自动发送；任一窗口取消均保持原会话及其目录。没有当前会话目录时显示空态，不沿用上次项目。未发送草稿可配置项目，但会话目标、参考资料和审查需发送首条消息后使用。

命令由所选环境的 `command/exec` 执行，使用 `/bin/sh -lc`，受服务端沙箱与权限约束。运行前可检查目录和命令，运行后展示流式日志、退出状态及停止入口；支持显式发送标准输入。测试／构建超时为 10 分钟，开发命令为 24 小时。一个连接同时只管理一项项目命令；断线或刷新后结果可能未知，先核实并确认后才能再次运行，不自动重试。日志可能截断；预览 URL 仅接受显式配置的 HTTP(S) 地址，打开链接不代表服务已就绪。

## Git 只读工具

Git 页保留分支、状态、目录树／列表、文件差异与刷新。右侧「Git 工具」菜单可导出已暂存或未暂存补丁，也可列出已有工作树；选择工作树目录会打开新建会话窗口，不修改原会话目录。未跟踪文件不包含在 Git diff 导出中。

暂存／取消暂存、提交、推送、创建 PR 和创建工作树的入口及执行代码已移除，不再根据权限配置展示。这些操作请在本机 Git 工具或终端中完成。右侧 Git 查询统一使用无网络的只读 command/exec，不修改沙箱配置，也不进行提权探测。Git 工作区可能包含手动或其他会话的修改，与「本轮变更」分别查看。

## 外观与数据保存

浏览器标签页标题跟随当前会话，格式为「会话标题 · Codex 工作台」；配置多个环境时增加环境名。当前会话执行时增加「执行中」前缀，有待回答或审批请求时优先显示「待确认」。断开的环境不沿用旧执行状态。切换会话、重命名和状态变化会同步更新标题，后台会话完成不改动当前标题。首页和未发送草稿显示「Codex 工作台」。

侧栏、搜索结果、会话页和浏览器标签页共用会话标题：已有名称优先，未命名时从已加载历史中取最早的有效用户需求，跳过「回答问题：」回复、纯日志、命令输出和代码块；没有已识别需求时尝试使用有效的会话预览。预览只有答复或日志且正文尚未加载时，显示「未命名会话」和创建日期，打开会话后再识别任务。名称、预览和正文都为空时显示「新会话」。已识别的任务标题在当前浏览器按环境与服务地址保存，刷新、预览变化或正文缓存回收后仍保留；加载更早的历史时可改用更早的有效需求，用户重命名始终优先。临时会话不持久化任务标题。不会为生成标题额外读取全部会话正文，也不会自动改写服务端名称。

浏览器标签页图标汇总所有环境，按以下优先级切换：

| 优先级 | 图标             | 显示与清除条件                                                                             |
| ------ | ---------------- | ------------------------------------------------------------------------------------------ |
| 1      | 带对勾的完成图标 | 有成功完成但尚未查看的主会话结果时显示，即使其他任务还在执行；查看相应会话后清除该会话提醒 |
| 2      | 带时钟的执行图标 | 没有未读完成结果，且已连接环境仍有任务执行时显示，包含后台会话与子代理                     |
| 3      | 产品图标         | 没有未读完成结果，也没有已知正在执行的任务时显示                                           |

侧栏会话标题左侧只展示一个当前状态图标：打开时显示加载，状态待同步、待处理、失败和运行状态优先于历史完成提示；空闲且结果未读时显示绿色圆形对勾，打开会话后清除。队列继续执行时，loading 会替代上一条任务的完成对勾，未读记录仍保留，可通过「未读结果」筛选或待办中心查看。正在查看的会话在可见且获得焦点的标签页中完成后直接恢复空闲或执行图标；标签页隐藏或浏览器窗口失去焦点（例如切换到其他应用）时完成则保留对勾提醒。切回页面只会清除当前所选环境、当前所选会话的完成提醒，其他会话需分别查看。关闭通知或通知自动消失不等于已读。子代理完成、失败、中断、等待审批不会被标为成功完成。已收到的未读完成结果在环境断开后仍保留；断开环境的旧运行状态不计入执行图标。刷新页面后，未读完成提醒随当前页面状态重置。

「设置 → 通用」支持浅色、深色和跟随系统。桌面导航与详情面板可调整或折叠，窄屏使用抽屉。

| 数据                                     | 保存位置与生命周期               |
| ---------------------------------------- | -------------------------------- |
| 会话历史、真实任务状态                   | Codex app-server 管理            |
| 工作环境配置、主题、默认模型、面板尺寸   | 当前浏览器本地存储               |
| 待发送队列及其中的附件                   | 当前浏览器 IndexedDB；恢复后暂停 |
| 未保存文本文件缓冲及读取基线             | 浏览器本地存储，按环境和地址隔离 |
| 未发送会话、普通输入文本和引用           | 浏览器本地存储，按环境和地址隔离 |
| 项目配置、说明和命令                     | 浏览器本地存储，按环境和地址隔离 |
| 未命名会话已识别的任务标题               | 浏览器本地存储，按环境和地址隔离 |
| 普通输入草稿中的图片附件                 | 当前页面内存；恢复后需重新添加   |
| Bearer Token、私密问题字段、同步回答摘要 | 当前页面内存，不持久化           |
| 普通问题答案草稿                         | 浏览器本地存储，按环境和问题隔离 |

未保存的文本文件恢复后显示提示，不自动写入磁盘；保存前再次读取磁盘，外部内容变更时进入现有冲突处理。每个环境和地址的编辑恢复副本最多 20 个文件、序列化内容最多约 2 Mi 字符；超过限制或浏览器存储失败时会显示警告，请先保存或复制内容。只保存编辑内容与基线，不恢复撤销历史和只读 Git Diff 标签。恢复副本不能替代磁盘保存，也不提供多标签页协同编辑。

有未保存的文件修改、草稿、待发送任务或正在提交的消息时，离开页面会请求浏览器原生确认；未持久化附件及存储失败的修改仍可能丢失。清理浏览器站点数据会删除本地配置、恢复副本、问题草稿和队列。工作台没有通用交互终端，真实推理和命令执行由所连接的 app-server 提供。

会话导出、附件、终端输出和浏览器截图可能含代码、个人路径或凭据，请保存到仓库之外，不要用于公开问题附件。共享或交接设备前检查站点存储；清除浏览器数据不会删除 app-server 管理的历史或认证。工作台仅面向本机单用户使用，不要通过公网隧道或反向代理公开访问。详见[安全与隐私](../SECURITY.md)。

项目配置查询与设备默认设置独立：在「查看项目生效配置」填写所选设备上的绝对目录，或点击「使用所选会话目录」，再点击「读取配置」。查询目录不会改变会话工作目录。读取后显示目录和结果，修改查询目录即清空旧结果；保存设备默认值后手动刷新查询结果。此结果是该目录下的配置合并结果，不代表当前会话的全部运行参数。

「通用 → 会话交互 → 完成后自动收起执行过程」默认开启。开启后，成功结束的轮次自动收起过程，失败和中断保留记录；用户消息、最终总结和轮次状态始终可见，仍可手动展开。偏好保存在当前浏览器。
