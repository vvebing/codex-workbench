# 界面重构计划

目标：保留 Codex Workbench 的真实功能与现有未提交改动，重构整个界面的视觉层级和操作体验，消除模板化装饰。

## 执行顺序

1. **评估与基线**：比较 Impeccable / Hallmark；审阅项目结构、现有改动及真实浏览器页面；选定工具与视觉方向。
2. **项目级安装**：将选中的技能安装到 `.agents/skills`，记录来源；复用已有全局 Impeccable 运行时，不改写全局配置。
3. **设计与实施**：GPT-6.1 子代理分工实施整体设计系统、导航与会话、设置与辅助功能；主代理负责范围协调及设计审查。
4. **集成检查**：覆盖中英文、浅色/深色、桌面/窄屏、空态/加载/错误、键盘焦点与主要交互，完成类型检查、构建和适当回归测试。
5. **真实浏览器验收**：通过 kimi-webbridge 访问 `http://127.0.0.1:5180`，检查各主要页面与关键操作，修复问题后记录最终结果。

## 验收标准

- 工作台视觉一致，主次操作清楚，装饰服务于功能；不用营销式大标题、渐变、重复卡片和装饰徽章。
- 保留会话、文件、任务、审批、环境和设置等既有能力。
- 响应式无整体横向溢出，长路径和长内容可读；键盘焦点、弹窗、表单反馈可用。
- 现有未提交修改不被覆盖；不执行真实任务发送、审批、环境删除等持久业务变更来验收。
- 项目级技能安装可追溯，全局 `/Users/vvebing/.impeccable` 保持原状。
